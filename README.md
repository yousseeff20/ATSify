# Applicant Tracking System (ATS)

This is the backend for the multi-tenant Applicant Tracking System built with .NET 8, Clean Architecture, and CQRS.

## Overview
This platform provides an API for managing recruitment pipelines, candidates, job posts, and multi-tenant configurations.

## Documentation
Please refer to the `docs` folder for architectural decisions and the `ATS_Software_Requirements_Architecture_Specification.md` for the full specifications.

## Prerequisites
- .NET 8 SDK
- SQL Server LocalDB (for local development)
